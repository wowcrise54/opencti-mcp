# OpenCTI MCP

Частичный перенос из проекта ChatGPT. В [docs](docs/) сохранены ответы из пяти чатов, включая техническое задание, архитектуру и код по этапам. В длинных ответах отмечены места, где инструмент чтения обрезал текст.

В `src/opencti_mcp` вынесены полные блоки кода с известными путями. Сервис графа и его MCP-обёртки взяты из одного этапа. Более поздняя асинхронная версия графа сохранена в [ответе этапа 3](docs/04-graph-async.md) вместе с началом её обёрток.

Для запуска по проектной спецификации нужны полные исходники `server.py`, сервис IoC, регистрация инструментов поиска и записи и материалы дальнейших этапов. Их доступные фрагменты сохранены в документации.
