# OpenCTI MCP

Частичный перенос из проекта ChatGPT. В [docs](docs/) сохранены ответы из пяти чатов, включая техническое задание, архитектуру и код по этапам. В длинных ответах отмечены места, где инструмент чтения обрезал текст.

В `src/opencti_mcp` вынесены полные блоки кода с известными путями. Сервис графа и его MCP-обёртки взяты из одного этапа. Более поздняя асинхронная версия графа сохранена в [ответе этапа 3](docs/04-graph-async.md) вместе с началом её обёрток.

Точка входа `opencti-mcp` регистрирует 18 инструментов поиска, графа, IoC и записи. Инструменты записи по умолчанию выполняют предварительную проверку (`dry_run=true`). Изменение данных требует включить `OPENCTI_MCP_WRITE_ENABLED=true`, использовать токен с нужными правами и передать `dry_run=false` и `confirm=true`.

Выгрузка возвращает одну страницу. Фильтры действительности, оценки и типа применяются к полученной странице, поэтому даже при пустом списке может быть доступен следующий курсор. Экспорт STIX содержит индикаторы без связанных объектов. Пакетный поиск использует существующий поиск наблюдаемых объектов.

## Развёртывание рядом с OpenCTI

Compose подключает MCP-контейнер к существующей сети OpenCTI на удалённом хосте. В `.env` на этом хосте задайте `OPENCTI_DOCKER_NETWORK` с именем сети, `OPENCTI_URL` с адресом по Docker DNS и `OPENCTI_API_TOKEN` с токеном отдельной учётной записи OpenCTI для чтения. Если внутренний адрес использует HTTP, задайте `OPENCTI_ALLOW_HTTP=true`.

Текущая конфигурация рассчитана на транспорт `stdio`. Соберите образ командой `docker compose build opencti-mcp`. MCP-клиент на этом же хосте может запустить сервер командой `docker compose run --rm -T opencti-mcp`. Порт на хосте не публикуется.
